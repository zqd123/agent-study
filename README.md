## 📁 目录结构

```
agent-study/
├── notes/   # 各章节学习笔记，按 chapter01～chapter16 组织
└── code/    # 实践代码
```

## 💡 学习方式

1. 按章节顺序学习教程，优先阅读在线版本。
2. 每章学习后在 `notes/chapterXX/` 下记录笔记与心得。
3. 跟随教程动手完成实践代码，放入 `code/` 目录。
4. 完成一章后勾选上方进度清单。
