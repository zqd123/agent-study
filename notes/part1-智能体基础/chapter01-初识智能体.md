## 🎯 本章目标

- 理解智能体的定义与四个基本要素
- 掌握智能体的类型划分与演进脉络
- 理解 LLM 智能体的运行机制（感知 → 思考 → 行动循环）
- 区分 Workflow 与 Agent 的本质差异

## 📖 核心概念

| 概念 | 解释 | 我的理解 |
| ---- | ---- | -------- |
| 智能体（Agent） | 能通过**传感器**感知**环境**，并**自主**地通过**执行器**采取**行动**以达成目标的实体 | 四要素：环境、传感器、执行器、自主性；核心是"感知→行动"的闭环 |
| 自主性（Autonomy） | 基于感知和内部状态独立决策，而非被动响应或执行预设指令 | 区分"智能体"和"普通程序"的分水岭 |
| 简单反射智能体 | 基于工程师写死的"条件-动作"规则，只看当前感知 | 数字本能：恒温器。快但无记忆、无上下文 |
| 基于模型的反射智能体 | 内部维护**世界模型**，追踪无法直接感知的状态 | 有了初级"记忆"：隧道里的车知道前车还在 |
| 基于目标的智能体 | 主动规划导向目标的行动（如 GPS 导航 + A* 算法） | 从"反应"升级为"规划"，会问"我该做什么" |
| 基于效用的智能体 | 为状态赋效用值，最大化期望满意度 | 学会权衡多目标：更快？更省油？更舒适？ |
| 反应式 vs 规划式 | 时间维度的权衡：即时响应（气囊、高频交易）vs 深思熟虑 | 核心矛盾：**速度 vs 最优解** |
| 符号主义 AI | 逻辑规则推理，可解释但脆弱（知识获取瓶颈） | 系统 2：慢而严谨 |
| 亚符号主义 AI（连接主义） | 神经网络从数据中学习模式，但不可解释 | 系统 1：快而直觉 |
| 神经符号主义 | 融合两者：模式识别 + 逻辑推理 | ⭐ LLM 智能体就是实践范例：神经网络内核 + 结构化符号输出（Thought/Plan/API 调用） |
| LLM 智能体新范式 | 决策引擎从"显式编程"变为"预训练涌现的世界模型" | 从**写代码解决问题** → **引导通用大脑解决问题** |
| PEAS 模型 | Performance / Environment / Actuators / Sensors | 描述任务环境的框架，设计智能体先写 PEAS |
| Thought-Action-Observation | LLM 智能体的交互协议：思考快照 + 具体行动 + 环境反馈 | ReAct 范式的雏形，1.3 节实战就靠它 |
| Workflow | 预先定义的静态流程图，按部就班执行 | 报销审批流：条件全写死 |
| Agent | 目标导向、自主推理、动态决策 | 天气晴推颐和园、下雨推国博——**没有写死 if-else** |

## 🔑 关键要点

1. **传统智能体演进线**：简单反射 → 模型反射 → 目标 → 效用（→ 学习作为元能力）。每一步都在回答一个新问题："当前感知不够了怎么办 → 世界现在什么样 → 我该做什么 → 哪种最满意"。
2. **LLM 带来的本质转变**：传统智能体能力源于工程师显式编程（确定、有边界）；LLM 智能体通过预训练获得隐式世界模型，能直接处理高层级、模糊的自然语言指令，且具备规划推理、工具使用、动态修正三大能力。
3. **LLM 智能体是神经符号主义的实践**：内核是神经网络（系统 1，模式识别），工作中生成结构化中间步骤——Thought、计划、API 调用（系统 2，符号推理）。
4. **任务环境四大特性**（数字环境）：部分可观察（需记忆+探索）、随机性（需处理不确定性）、多智能体（需应对其他行动者）、序贯且动态（当前动作影响未来）。
5. **运行机制核心循环**：观察（感知）→ 思考（规划 + 工具选择）→ 行动（调用工具）→ 环境状态变化 → 新观察……循环推进直至目标达成。
6. **感知系统的重要职责**：把工具返回的原始 JSON 封装成简洁自然语言的 Observation，才能供 LLM 消费。
7. **两种协作模式**：作为开发者工具（Copilot、Claude Code、Cursor——增强人）vs 作为自主协作者（BabyAGI/AutoGPT → CrewAI/MetaGPT/AutoGen/LangGraph——委托目标）。
8. **多智能体三大范式**：单智能体自主循环（AgentGPT 式自迭代）、多智能体协作（角色对话 CAMEL / 组织化工作流 MetaGPT、CrewAI）、高级控制流（LangGraph 状态图，支持循环/分支/回溯/人工介入）。
9. **Workflow vs Agent 一句话**：Workflow 让 AI 按部就班执行指令，Agent 赋予 AI 自由度自主达成目标。判断标准：有没有**基于实时信息的动态推理**。

## ❓ 疑问与思考

- ChatGPT 纯对话框算智能体吗？——按定义它缺少对环境的**行动/工具调用**环节，更接近"LLM 本身"；加上工具调用后才成为智能体。
- 反应式与规划式的平衡点在哪里？实际工程中似乎多数场景要混合（快系统保底，慢系统规划）。
